AI Tools For Owners (A.T.F.O.) logo files
==========================================

SVG files scale to any size (use them for the website, print and signs).
PNG files are large and have transparent backgrounds.

Files
- atfo-icon            The check-mark icon. Use for social profile pictures, app icons, favicons.
- atfo-icon-yellow     Same icon in yellow, for places where blue clashes.
- atfo-logo-horizontal Icon + "AI Tools For Owners" on one line. Main logo for headers and emails.
- atfo-logo-stacked    Icon above two lines of text. The main logo. For square spaces and social posts.
- atfo-logo-stacked-card  The stacked logo on a light rounded card, ready to post or print.
- atfo-logo-acronym    Icon + "A.T.F.O." for small spaces.
- "-white" versions    Use on dark backgrounds.

Colors
- Ballpoint blue  #2B36E8
- Highlighter     #FFE94D
- Ink (text)      #12142E
- Paper           #EDEFF5

Typeface: Bricolage Grotesque. The first letter of each word (A, T, F, O) is set heavy and the rest light, so the name also reads as ATFO. Lettering is converted to shapes, so no font is needed.
Leave clear space around the logo at least the height of the icon's check mark.
